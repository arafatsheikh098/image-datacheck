feat(m3): integrity checks, multiprocessing, 20k perf measurement

- src/imagedatacheck/integrity.py: per-file integrity check (full decode,
  not just verify(), so truncated files are caught). Reports E_UNREADABLE,
  E_ZERO_BYTE, E_TOO_SMALL, E_TRUNCATED, E_DECOMPRESSION_BOMB,
  E_WRONG_EXTENSION, I_CMYK, I_PALETTE_TRANSPARENCY, I_EXIF_ORIENTATION,
  W_LOW_INFORMATION.  run_integrity_checks() runs across a list of paths
  with --workers=1 (sequential) or workers>1 (spawn-pool).  Top-level
  _worker function is picklable for Windows + macOS spawn.
- src/imagedatacheck/cli.py: scan command now invokes integrity after the
  walk, with the requested --workers.
- src/imagedatacheck/layout.py: lowered class_folders detection threshold
  to >=1 class so single-class datasets are recognised; tightened
  hidden-file detection so a dataset root whose own name starts with a
  dot (e.g. /tmp/.scratch) is still walked.
- src/imagedatacheck/scanner.py: pass path-relative-to-root to is_hidden()
  so the root itself is not treated as hidden.
- scripts/measure_20k.py: produces 20k images and measures wall time and
  peak RSS delta.
- tests/test_integrity.py + tests/test_memory.py: 17 new tests covering
  every planted finding type, workers=1 vs workers=4 parity, picklability
  of the worker, one-bad-file-doesnt-abort, and a slow 20k benchmark
  (default 500 files; set IDC_FAST_MEMORY_TEST=1 for CI).
- pyproject.toml: added slow pytest marker.
